# 03_BACKEND_MASTER_PROMPT.md

Build the backend/control plane for Forge.

## Stack
- Python FastAPI
- Nhost PostgreSQL
- Nhost Auth
- Upstash Redis
- Inngest
- Fly.io MicroVM sandboxes

## Responsibilities
- API gateway
- orchestrator
- C-Suite execution
- idea generation and curation
- PRD generation
- architecture planning
- design studio orchestration
- capability gate
- secrets vault handling
- code generation coordination
- sandbox lifecycle
- deployment coordination
- learning and reflection

## Hard rules
- platform core must not use Supabase
- generated apps may optionally use Supabase only when selected
- block heavy backend services in sandbox
- enforce secret safety and auditability
- model specialized-agent collaboration explicitly
