# Editor Conversational AI System (v10)

The Monaco editor includes a built-in AI assistant.

This assistant should be positioned as a coordinated interface into many specialist agents, not a single generic chatbot.

Supported actions:
- ask questions about code
- request UI edits
- add features
- debug errors
- refactor code
- restart/rebuild sandbox
- request deployment
- ask architectural questions
- ask for cloud-service integration guidance

When appropriate, the assistant routes requests to:
- design agents
- code agents
- repair agents
- sandbox agents
- deployment agents
- planning agents
