C-Suite Analysis Framework

Each C-Suite agent should produce output in a structured format, not loose chat.

Every agent should analyze the same opportunity, but from its own specialist perspective.

Each agent should return:

Executive Summary
What this agent cares about
Opportunity assessment
Risks / concerns
Recommendations
Impact on downstream teams
Decision signal
Structured output block
Shared input all C-Suite agents receive

Each agent should receive:

raw user prompt or selected idea
enhanced prompt if available
user ideation answers if available
workspace/project context
selected product mode if known
known stack constraints
known sandbox constraints
known security constraints
monetization assumptions if any
target customer hints if known

11. Best practice for how they should work together

The C-Suite should not run as one giant blended prompt.

The best flow is:

each specialist agent runs independently
each returns structured analysis
results are normalized into shared schema
Executive Synthesizer merges them
downstream agents consume the synthesized result

That gives:

better specialization
cleaner traceability
better UI presentation
stronger user trust
12. What the user should see in the UI

To build trust, the user should see:

each C-Suite role as a distinct card/panel
what each role focused on
short analysis summary
confidence level
where agents agree/disagree
final executive synthesis

This makes the system feel like:
a coordinated boardroom + product org + design/engineering org working on the user’s behalf
