# Forge Execution Contract Pack

This pack is the production-depth implementation spec layer intended to sit on top of the existing Forge build pack.

It defines:
- API contracts
- screen-by-screen state models
- database schema in production detail
- event and workflow contracts
- agent input/output schemas
- secret vault lifecycle
- capability gate decision matrix
- sandbox policy enforcement rules
- integration and acceptance criteria
